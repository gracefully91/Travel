# 리조트권 외곽과 바랑재

- 날짜: 2026-11-12
- 상태: 완료 (외곽 모양은 사용자 확인 대기)
- 기록: [#15 리조트권](../work/%2315%20resorts-area.md)

## 목표와 범위

사용자가 제공한 북쪽 위 OSM 이미지 765×685px와 동서남북 내보내기 좌표를 사용해 리조트권 기본 3D 맵을 만든다. 주소 올림픽로 1169의 바랑재를 실제 확인한 좌표로 추가한다. 상세 슬로프·스키하우스 및 실제 고도는 후속 작업이다.

## 결정

- bbox 서128.55686·남37.58458·동128.82637·북37.70094는 원본 수집 범위로 보존한다. 이미지 전체에 이 bbox를 대응시킨 최초 구현은 전체 범위를 넓힌 오류라 폐기했다.
- 이미지의 투구봉·용산·발왕산·1220m 삼각점 정상 기호를 실제 OSM node 좌표에 맞춰 북쪽 위 Web Mercator의 동일 축척과 평행이동을 구한다. 픽셀 표시는 텍스트 위치가 아닌 정상 기호를 따른다. 빨간 외곽 64점은 보존하고 새 변환으로 적용한다. RMS 약 1.45px이며 수작업 픽셀 오차는 남는다.
- OSM 전체 요청은 50,000 node 제한에 걸려 3×3 타일로 나눠 수집 후 ID로 중복 제거한다. 타일과 이전 원본 모두 보존한다.
- 알펜시아·모나용평·바랑재는 같은 기본 맵을 사용한다. 클릭하면 확인창 없이 입장하며 실제 지리 좌표에 장소 라벨을 표시한다.
- 바랑재 주소와 설명은 공식 사이트를 확인한다. 동명 다른 지역의 Nominatim 결과는 사용하지 않는다. 공식 안내에 포함된 주소 지도 마커를 변환해 사용한다.
- 기존 선호대로 브라우저 캡처 없이 데이터 검사·빌드·문서 확인 후 알린다.

## 완료 조건

3D 데이터 생성, 세 장소의 경계 내 포함, 실제 클릭 진입 연결, 공식 바랑재 주소 좌표 출처 보존, 빌드와 문서 검사 통과.
