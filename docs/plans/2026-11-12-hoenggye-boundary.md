# 횡계 OSM 내보내기 좌표 기반 경계

- 날짜: 2026-11-12
- 상태: 진행 중 (적용 완료, 사용자 확인 대기)
- 작업 기록: [#14](../work/%2314%20hoenggye-boundary.md)

## 목표와 결정

사용자가 제공한 OSM 북쪽 위 지도 807×715px와 내보내기 bbox [128.67973,37.65766,128.74711,37.68674]를 사용한다. 빨간 외곽을 67개 픽셀 점으로 추적하고 Web Mercator 역변환 후 로컬 미터로 옮긴다. 임의 회전/타원은 사용하지 않는다. 원본·변환 기준을 보존하며 캡처 검토는 생략한다.

## 완료 조건

- export bbox와 이미지 끝점이 일치하고 외곽 전체가 원본 OSM 범위 안에 있다.
- 3D용 변환 데이터와 수집 범위를 일치시킨다.
- 데이터 검사와 빌드/문서 링크 확인 후 사용자에게 바로 알린다.
- 픽셀 추적 오차와 지도 전체 이미지에 bbox를 맞춘 가정을 기록한다.
## 후속 범위: 화면 표시선으로 정밀 절단

사용자가 최신 3D 화면의 빨간 선을 따라 자르고, 선이 없는 아래쪽은 유지하는 것으로 확인했다. 기존 외곽의 평면 투영을 화면 실루엣에 정합한 뒤 표시선을 역변환한다. 원래 export 기준은 보존한다. 양 끝점을 기존 경계에 붙이고 그 사이 아래쪽 기존 외곽 점은 유지한다. 캡처 없이 데이터 검사·빌드 후 바로 적용 사실을 알린다. 화면에 실제 카메라 행렬이 첨부된 것은 아니므로 실루엣 정합과 수작업 픽셀 오차는 명시한다.
