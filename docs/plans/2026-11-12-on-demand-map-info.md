# 기본 3D 맵 정보 온디맨드 표시

- 작성일: 2026-11-12
- 상태: 완료
- 관련 작업 기록: [#11 기본 맵 정보 표시](../work/%2311%20on-demand-map-info.md)

## 목표

기본 시내 맵에 진입했을 때 상시 정보 패널이 3D 공간을 가리지 않도록 숨긴다. 장소나 건물을 선택하면 기존에 있던 해당 정보를 필요할 때 볼 수 있게 한다. 우측 상단 복귀 버튼은 기존 `다른 작은 세계로 이동` 녹색 버튼의 모양과 문구를 사용한다.

## 범위와 완료 조건

1. 진입 직후 장소 정보 패널은 닫혀 있고 지도 공간을 차지하지 않는다.
2. 장소 라벨을 누르면 설명·실제 데이터 개수·고도 및 높이/폭 근사·출처가 표시된다.
3. 건물 클릭 정보와 OSM 원본 링크를 유지하고 닫기 버튼을 제공한다.
4. 상단 우측 버튼이 데스크톱·모바일에서 같은 문구/시각 스타일로 구역 지도로 이동한다.
5. 구역/포털 브라우저 검사, 빌드와 문서 링크 검사를 통과한다.

## 결과

완료. 전체 패널 코드와 장소/건물 정보 표시를 보존하고, 선택 상태에서만 나타나도록 했다. 상세 검증은 #11 기록 참고.
