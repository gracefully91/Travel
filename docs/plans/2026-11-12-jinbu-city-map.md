# 진부 시내 불규칙 경계 3D 맵

- 작성일: 2026-11-12
- 상태: 완료
- 관련 작업 기록: [#10 진부 시내 맵](../work/%2310%20jinbu-city-map.md)

## 목표

사용자가 제공한 빨간 외곽선을 따라 진부 터미널거리의 탐험 범위를 넓히고, 지도 마커와 진부역 도로 포털에서 실제 OSM 기반 3D 시내 맵에 직접 들어간다.

## 범위와 결정

- 기존에 저장된 `data/raw/regions/jinbu.osm`을 사용한다. 경계 외곽선은 참고 스크린샷에서 근사하며 OSM/네이버 원본 지도 데이터를 추출하지 않는다.
- 불규칙 경계 안의 실제 OSM 건물·도로·철도·수로·녹지를 선택한다. 도로 중심선은 경계와 만나는 곳에서 잘라 경계 밖까지 이어 그리지 않는다.
- 기존 장소 ID, BIS 터미널 중심과 역↔시내 포털 연결은 유지한다. 시내 지면만 경계 다각형으로 바꾸고 카메라/클리핑 범위를 맵 크기에 맞춘다.
- 고도 DEM, 높이·폭 추정 정책, 상세 건물 외관은 이번 범위에서 다루지 않는다.

## 완료 조건

1. 진부 시내 맵은 정사각형 고정 타일 대신 저장된 불규칙 경계 지면을 사용한다.
2. 실제 OSM 건물·도로·수로가 범위 안에 배치되고 주요 중심선은 외곽에서 잘린다.
3. 마커 클릭과 역↔시내 포털 이동이 동작하며 모바일 화면과 기존 다른 맵은 유지된다.
4. 빌드, 관련 브라우저 검사, 문서 링크/번호 검사를 실행하고 한계와 출처를 기록한다.

## 결과

완료. 원본 OSM 좌표를 보존하고, `scripts/process-regions.py`가 참고 이미지형 경계와 시내 features를 `public/maps/jinbu-town.json`으로 변환한다. 검사 결과는 작업 기록에 있다.

후속 피드백에서 최초 범위가 역까지 포함해 컸음이 확인되어 별도 [둥근 시내 경계 조정](2026-11-12-rounded-jinbu-boundary.md)으로 조정하고 역/철도 feature를 분리했다. 이 계획의 초기 18점·182건물 범위는 당시 구현 이력이다.
