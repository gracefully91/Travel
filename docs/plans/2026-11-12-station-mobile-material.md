# 진부역 GLB 모바일 재질 표시 수정

- 날짜: 2026-11-12
- 상태: 완료
- 작업 기록: [#18](../work/%2318%20station-mobile-material.md)

## 목표

GitHub Pages의 모바일 화면에서 검게 보이는 진부역 GLB를 기존 텍스처를 보존하면서 밝게 표시한다.

## 원인과 결정

GLB는 텍스처를 포함한 단일 metallic-roughness PBR 재질을 사용한다. 장면에는 금속 표면의 반사광을 제공할 환경 맵이 없으므로 금속 반응을 낮추고 거칠기를 높여 장면 조명에서 재질이 읽히게 한다. 원본 GLB와 텍스처 파일은 변경하지 않는다.

## 완료 조건

- GLB의 base-color/normal/metallic-roughness 텍스처를 유지한다.
- 금속도가 최대 0.08, 거칠기가 최소 0.72가 되도록 화면용 재질만 조정한다.
- 프로덕션 빌드가 성공하고 브라우저 렌더에서 역사 표면이 검은 덩어리로 보이지 않는지 확인한다.
