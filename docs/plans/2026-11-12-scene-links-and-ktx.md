# 도로를 따라 연결하는 작은 맵과 시간표 열차

- 작성일/최종 갱신: 2026-11-12
- 상태: 완료
- 관련 작업 기록: [#6 도로 포털·시간표 KTX](../work/%236%20road-portals-and-scheduled-ktx.md)

## 배경과 목표

사용자는 진부역에서 시내로 이어지는 실제 길에 다음 3D 맵 표지판을 두고, 제공된 KTX-Sancheon.glb를 방향별 실제 열차 시각에 맞춰 운행시키길 요청했다. C:/dev/@ project-starter의 문서 규칙과 지금까지의 작업 기록도 적용한다.

## 확인된 사실과 가정

기존 역/시내 맵과 이동 안내/로딩이 있다. 모델은 Draco 압축 669,268바이트이고 압축 전 동형 모델은 203.71×3.97×2.91m 크기로 측정됐다. 코레일 공개 게시판에서 2026-11-01 시행 KTX 시간표 첨부 XLSX를 확보했다. 이 자료는 계획 시간표이며 실시간 운행 위치가 아니다. 시내 연결점은 공개 도로 경로와 OSM 중심선에 근거해 선택하며 표지판 자체는 앱 UI다.

## 범위와 결정

- 포함: 진부역↔진부 시내 도로 표지, 클릭 기반 기존 이동 안내 재사용, 실제 GLB 열차와 로컬 시간표, 요일/한국 시각/방향 검증, 수동 강릉 데모, 문서 체계/회고.
- 제외: 실제 지연·GPS 추적, 미정차 열차의 추정 통과시각, 리조트 상세 맵, 자동 지역 이동.
- 사용자 확정: 2026-11-12 현재 요청. 시간표의 진부 정차 시각을 미니어처 통과 애니메이션의 기준으로 사용하며 실제 위치를 주장하지 않는다.

## 실행 단계와 완료 조건

1. OSM 도로와 공개 경로에서 실제 연결 방향을 확인하고 두 맵의 표지를 배치한다. 클릭·왕복·취소·단일 Canvas를 브라우저 검사한다.
2. GLB 크기/축/재질/성능을 분석하고 양방향 연결 선로에 배치한다. 실제 모델 로드, 진행 방향, 수동 데모, 일시정지를 확인한다.
3. 공식 XLSX 원본과 변환 JSON·출처/시행일/확인일을 보존한다. 요일, 자정, 중복 방지, 반대 방향, 오래된 자료 제외를 테스트한다.
4. AGENTS/BRAIN/계획/작업/인덱스를 작성하고 링크와 실제 상태를 대조한다.

## 미결 사항과 위험

실시간 지연은 미지원이며 시간표만으로 미정차 열차의 역 통과 시각을 알 수 없다. KTX-산천 모델을 다른 실제 편성(KTX-이음 등)의 시각에도 대표 시각화로 사용하며 차종 일치는 주장하지 않는다. 선로는 OSM 주행 방향에 맞추고 실제 승강장 배정은 확인되지 않았다. 공식 시간표에 없는 공휴일 특수 운행은 추정하지 않는다.

## 변경 및 결과

2026-11-12: 도로 연결점 원본·양방향 포털·실제 GLB/로컬 Draco·공식 시간표 변환·KST/요일/방향·수동 강릉 데모·문서 체계를 구현했다. 빌드, 시간표 7개·포털/열차 19개·기존 지도 29개 검사와 문서 링크 검사가 통과했다. 실제 지연/위치·승강장 배정·공휴일 특수 운행 미확보 등 한계는 유지하며 자세한 결과는 관련 작업 기록에 있다.

### 후속 결정으로 대체된 부분

2026-11-12 사용자 요청으로 철도 방향/통과 표현은 [중앙 두 선로·우측통행·1분 정차 계획](./2026-11-12-train-arrival-dwell.md)으로 대체한다. 원래 구현 당시에는 OSM 철도 방향과 통과 표현을 사용했으며, 이 완료 기록은 당시 결과를 보존한다. 맵 포털과 시간표 데이터 결정은 유지한다.

2026-11-12 추가 후속: 맵 전환의 이동 안내/확인 단계는 사용자 요청에 따라 [직접 입장 계획](./2026-11-12-direct-scene-entry.md)으로 대체한다. 원형 마커·장소 목록·입장 버튼·도로 표지는 즉시 로딩을 시작한다.
