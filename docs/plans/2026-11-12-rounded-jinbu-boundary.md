# 진부 시내 경계 재조정

- 작성일: 2026-11-12
- 상태: 진행 중
- 관련 작업 기록: [#12 둥근 진부 시내 경계](../work/%2312%20rounded-jinbu-boundary.md)

## 목표

진부 터미널 거리의 3D 탐험 영역이 진부역 맵과 겹치지 않도록 하면서, 사용자가 빨간 선으로 표시한 진부 시가지 범위를 불필요하게 잘라내지 않는다.

## 범위와 결정

- 현 앱 경계는 사용자가 제공한 지도 표시를 기준으로 다듬는다. 참고 이미지 기반 근사와 실제 좌표 추적을 구분해 기록한다.
- 역 본관과 철도 feature는 시내 맵에서 제외하고 역 전용 맵에 둔다.
- 역 연결 표지는 저장된 실제 도로 경로 위에 둔다.
- 원본 OSM 데이터는 유지한다. DEM과 건물 높이·도로 폭 근사는 이번 작업 범위에 포함하지 않는다.

## 완료 조건

1. 터미널·시장 주변 주요 도로와 건물이 경계 안에 남고, 근거 없이 잘린 영역이 없다.
2. 진부역 본관과 철도가 시내 맵에 중복되지 않는다.
3. 역 연결 포털이 시내 맵 경계 안의 실제 도로 위에 표시된다.
4. 관련 브라우저 검사, 빌드, 문서 링크 검사를 수행하고 정확한 한계를 기록한다.

## 현재 상태

현재 경계는 약 1.6×1.4km 둥근 곡선으로 넓혔으며 역 건물과 철도는 제외된다. 그러나 경계 좌표는 표시된 빨간 외곽선을 직접 좌표화하지 않고 근사해 생성했으므로, 사용자의 마지막 피드백에 따라 정확한 외곽 정합은 미완료 상태다.
