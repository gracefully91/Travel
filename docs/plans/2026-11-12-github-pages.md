# GitHub 공개 저장소와 Pages 배포

- 날짜: 2026-11-12
- 상태: 완료
- 목표: 공개된 `gracefully91/Travel` 저장소에 프로젝트를 푸시하고 GitHub Pages에서 3D 지도 앱을 열 수 있게 한다.
- 결정: Pages는 정적 호스트이므로 Vite 앱의 공개 파일 경로를 `/Travel/` 기준으로 맞춘다. 서버의 `/api/travel/*`는 Pages에서 실행되지 않으므로 교통 일정 기능은 정적 데이터 경로로 옮기기 전까지 제한이 있다.
- 데이터 기준: 현재 공개된 저장소에는 KTX 정차 시간표, 버스 노선/정류장 정보, 도로 이동 시간 일부 스냅샷이 있다. SQLite 런타임 DB는 Git에서 제외되어 있으며, 현재 공식 BIS 노선 데이터로 확인된 확정 버스 시간표는 0건이다. 미확인 운행 시간을 임의 생성하지 않는다.
- 미결: 검증 가능한 버스 운행표 범위와 갱신 주기. GitHub Pages에서 일정 생성에 필요한 정적 경로/시간 자료를 브라우저 로컬로 제공하는 방식.
- 완료 조건: main 푸시, Pages workflow 성공, 구역 지도·소형 3D 맵·GLB/모델 경로 정상 로딩. 교통 일정 기능/API 한계는 사용자에게 정확히 표시한다.
- 완료: `https://gracefully91.github.io/Travel/` 배포, 공개 정적 모드에 교통 snapshot 연결. BIS에 검증된 새 버스 시간표가 부족하므로 확인된 시간만 사용하고 오래된 시간은 자동 일정에서 제외한다.
