# 기본 맵 정보 패널 표시 방식

- 작업 번호: #11
- 날짜: 2026-11-12
- 상태: 완료
- 관련 계획: [정보 온디맨드 표시](../plans/2026-11-12-on-demand-map-info.md)

## 요청과 결정

사용자는 기본 진입 시 보이는 `A LITTLE WORLD IN JINBU` 정보 패널을 없애되, 정보 코드를 제거하지 말고 추후 선택 동작으로 보이길 원했다. 상단 오른쪽의 `구역 지도로` 버튼을 `다른 작은 세계로 이동` 디자인으로 바꾸길 요청했다. 기존 지도 위 장소 라벨과 OSM 건물 선택을 각각 정보 표시 트리거로 사용했다.

## 변경 내용

| 파일 | 변경 내용 |

## 남은 한계

장소 정보는 지도 위에 표시된 장소 라벨에서, 건물 정보는 실제 건물 메시 선택에서 연다. 정보는 팝업 지도 핀이 아니라 화면 좌측 카드에 표시된다. 더 많은 OSM POI에 별도 클릭 정보/장소 라벨을 붙이는 일은 후속 범위다.
