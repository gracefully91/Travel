# 파일 기반 프로젝트 협업 문서 체계 설정

- 작업 번호: #5
- 날짜: 2026-11-12
- 상태: 완료
- 관련 계획: [맵 연결·KTX](../plans/2026-11-12-scene-links-and-ktx.md)

## 요청과 완료 조건

사용자 지정 C:/dev/@ project-starter의 README와 5개 템플릿을 읽고 실제 프로젝트에 맞춘 AGENTS/BRAIN/계획/작업/인덱스를 구성한다. 기존 문서는 보존하고 지금까지의 작업을 회고로 구분해 기록한다.

## 변경 내용

- 루트 AGENTS.md: 템플릿의 시작 순서·최소 원인 수정·작업 기록·검증 규칙과 실제 기술/명령/데이터 보존 경계를 채웠다.
- BRAIN.md: 현재 유효한 목표, 구현/제한, 확정된 구역 맵·좌표·교통/열차 결정을 정리했다.
- docs/plans/2026-11-12-scene-links-and-ktx.md: 사용자 확정 기능의 목적·사실/가정·범위·완료 조건·위험을 정리했다.
- docs/work/#1~#4: 기존 진부 MVP, 일정/DB, 구역 전환, 안정화/통행 수정의 회고. 개별 시각을 지어내지 않았다.
- docs/work/summary-index.md: 파일명 # 및 공백을 인코딩한 링크. 기존 README/MAPS/PLANNER/TRANSIT_DB는 유지한다.

## 검증

scripts/check-doc-links.mjs로 문서 링크·작업 고유 번호를 검사해 통과했다. 문서에 비밀키·개인정보·큰 로그는 복제하지 않았다. 스케줄러/외부 게시/원격 서비스는 생성하지 않았다.

## 남은 일과 재개 지점

기능 완료 결과·실제 검사·문서 링크를 대조하고 BRAIN/계획을 갱신했다. 다음 작업부터 AGENTS → BRAIN → 인덱스 순서로 읽는다.

## 문서 반영

- 작업 인덱스: 반영
- 관련 계획: 현재 계획에서 연결
- BRAIN: 현재 구현과 제한으로 요약 반영
