# 구역 지도와 작은 3D 맵 전환 회고

- 작업 번호: #3
- 날짜: 2026-11-12
- 상태: 완료
- 관련 계획: 기존 대화 기반 회고

## 기록 성격

2026-11-12에 기존 구현과 MAPS.md 및 세계 지도 검사 보고서로 작성한 회고다.

## 요청과 결정

사용자는 연속 오픈월드보다 메이플스토리처럼 구역을 선택해 로딩 후 작은 맵으로 들어가는 구조를 확정했다. 리조트는 추후 슬로프·스키하우스 주변만 상세 제작한다.

## 변경 내용

- src/world/registry.ts, WorldOverview.tsx, BasicScene.tsx, TravelGate.tsx, SceneReady.tsx 및 src/App.tsx: 진부권·횡계 시내권·리조트권 개요와 선택/안내/로딩/한 장면 렌더링.
- public/maps/jinbu-town.json: 실제 OSM 건물 51개. hoenggye-center.json: 122개. 상세 역 맵과 서로 다른 중심 좌표를 사용한다.
- data/raw/regions와 public/maps: 원본/변환 분리. 네이버 제공 스크린샷은 구역 기획 참고이며 데이터를 추출하지 않았다.
- 알펜시아·모나용평은 실제 대표점만 있고 상세 맵 입장은 비활성화돼 있다.

## 검증

기존 artifacts/world-test-report.json에서 검사 16개와 오류 0개를 확인했다. 맵 미진입 시 Canvas/역 GLB 요청 없음, 로딩 취소, 1개 Canvas, 두 시내 맵별 건물 수, 모바일과 일정 연결을 검사했다. 원본 취득일과 bbox는 ../../MAPS.md에 있다.

## 한계와 재개 지점

이 시점에는 3D 도로 표지로 맵끼리 직접 이동하는 연결이 없었다. 현재 계획에서 이 연결을 추가한다. 시내 건축 외관·광역 산악 지형과 실제 리조트 상세 모델은 미구현이다.
