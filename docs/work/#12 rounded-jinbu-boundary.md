# 진부 시내 경계 재조정

- 날짜: 2026-11-12
- 요청 목적: 사용자가 표시하지 않은 부분까지 잘리고, 역과 시내 구역이 겹치지 않게 시내 3D 경계를 조정한다.
- 원인/결정 배경: 초기 도시 범위는 진부역까지 포함했다. 이를 줄이는 과정에서 단순 타원으로 대체하여 사용자가 표시한 범위보다 안쪽으로 잘랐다. 타원 자체도 표시선을 추적한 것이 아니므로, 현재 넓은 둥근 경계는 임시 근사로 기록한다.
- 변경 내용:
  - `scripts/process-regions.py`: 진부 시내 경계를 둥근 약 1.6×1.4km 범위로 확장. 역 본관과 철도 feature를 시내 맵에서 제외하고 도로 중심선은 경계에서 자른다.
  - `public/maps/jinbu-town.json`: 변환 지도에 OSM 건물 170개, 도로·하천·녹지와 경계 저장. 원본 OSM은 수정하지 않았다.
  - `data/processed/scene-connections.json`: 역으로 가는 포털을 저장된 OSRM 경로의 시내 경계 근처 실제 도로 위에 배치.
  - `tests/world-browser.mjs`: 경계 형태·크기, 역/철도 제외, 포털 위치, 화면 내 포털 표시를 검증.
  - `MAPS.md`, `BRAIN.md`, 작업 인덱스: 범위 및 근사 경계 한계를 문서화.
- 검증:
  - `npm run maps:process`: 완료. `jinbu-town` 283 features, 건물 170개, extent 913m.
  - `npm run test:world`: 25개 검사 통과(현재 구현 스냅샷에서 경계·포털 표시 포함).
  - `npm run test:portals-trains`: 19개 검사 통과, 브라우저/에셋 오류 없음.
  - `npm run build`: 성공. Vite가 일부 청크 500kB 초과 경고를 출력했으며 이번 변경으로 인한 오류는 없다.
  - `npm run test:docs`: 문서 26개·링크 60개 검사, 누락 링크 없음.
- 남은 한계: 사용자가 그린 외곽선을 지리 좌표로 직접 추적한 데이터가 없어 둥근 경계는 약 1.6×1.4km의 수식 기반 근사다. 사용자의 마지막 피드백대로 표시선과 정확히 일치하지 않을 수 있어 해당 부분은 미완료다. 현재 확인된 역과 선로는 제외됐지만, 외곽 범위 최종 정합은 추가 수정 대상이다.
