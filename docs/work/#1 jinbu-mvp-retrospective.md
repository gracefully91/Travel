## 기록 성격

2026-11-12에 기존 대화·코드·README·검사 산출물을 대조해 작성한 회고다. 당시의 개별 변경 시각과 커밋을 복원한 기록은 아니며 이 폴더는 Git 저장소가 아니다.

## 요청과 완료 조건

진부역을 중심으로 실제 OSM 도로·건물·철도와 제공 역사 GLB를 배치하고 자유로운 카메라, 사람/차량과 Day 1 이동 데모를 구현한다.

## 변경 내용과 근거

- src/components/Scene3D.tsx, StationModel.tsx, Environment.tsx, Railway.tsx, LivingCity.tsx: 실제 R3F 장면과 GLB·절차적 지도·생활 애니메이션.
- src/lib/geo.ts, osm.ts, routing.ts 및 data/raw, data/processed: 실제 좌표와 로컬 미터 변환. 중심 37.64273279258768, 128.57445636859865.
- src/StationExperience.tsx, src/style.css: 장소 선택, 카메라 조작, Day 1 동선, 모바일 패널. Day 2~4는 확장 예정.
- 역사 GLB는 단일 재질 모델에 코드 재질과 유리를 보강했다. 유리 위치 이슈는 사용자 요청으로 보류했다.

## 검증

기존 artifacts/test-report.json에서 Edge software WebGL의 29개 검사 및 오류 0개를 확인했다. 이는 2026-11-12 KST에 생성된 기존 산출물이며 이번 문서 작성으로 당시 검사를 새로 수행했다는 뜻은 아니다. 지리 축·역/도로/철도, 실제 차량 이동, 회전·확대·이동, 장소 UI와 모바일 터치를 포함한다.
