## 요청과 완료 조건

중앙의 직선 본선 두 개만 사용해 앱에서 우측통행하도록 한다. 차체는 맵 밖 경계부터 부분적으로 들어오고, 진부역에서 약 1분 정차한 뒤 반대편으로 차체 전체가 빠져나가야 한다. 자동 시간표와 수동 강릉 데모에 같은 과정을 적용한다.

## 원인 또는 결정 배경

기존 열차는 OSM 철도 노드 방향을 따랐으며 수동 데모는 역 앞 140m에서 전체 모델을 표시했다. 이번 요청은 실제 철도 규칙을 새로 확인하라는 것이 아니라 중앙 선로/우측통행/정차를 지정한 앱 연출 변경이다. 원본 좌표와 oneway 태그를 고치지 않고 표시 경로만 반전했다.

## 검증 중 수정한 점

첫 픽셀 검사에서는 시각만 바꾸고 같은 접근 단계의 다음 프레임을 기다리지 않아 이전의 바깥 포즈를 다시 읽었다. 기대 단계뿐 아니라 해당 시각의 경과 시간까지 확인해 렌더링된 프레임을 기다리도록 수정했다. 기존 열차 시작 검사도 고정 600ms 후의 거리만 보던 방식에서 실제 데모 접근/경과 상태를 기다리도록 바꿨다. 고밀도 GLB가 표시된 소프트웨어 렌더링에서는 전체 보기 검사도 고정 1.5초 안에 목표 거리에 도달하지 않아 실패했다. 이 검사 역시 실제 카메라 거리 조건을 기다리도록 바꾼 뒤 29개 전체 검사를 통과했다. 단순 시작 수치나 임의 지연으로 검사를 통과시키지 않았다.

## 한계와 재개 지점

중앙 두 선로의 우측통행과 60초 정차는 사용자 지정 앱 연출이다. OSM 원본 철도 방향과 반대일 수 있으며 실제 정차/승강장·차종·지연을 확인한 결과가 아니다. 기존 시간표 원본·요일·검토기한과 자동차 통행은 유지했다. 자동 열차는 재개 시 현재 시각에 맞추고, 수동 데모의 일시정지 시간은 연출 시계에 더하지 않는다. 모든 GPU 성능이나 실제 열차 운행을 현장에서 측정한 것은 아니다.
